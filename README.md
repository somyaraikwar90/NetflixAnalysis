# NetflixAnalysis

# 📊 Netflix EDA & Dashboard Project

A complete Exploratory Data Analysis (EDA) and Power BI Dashboard project analyzing Netflix’s content library. This project is designed for showcasing data cleaning, analysis, visualization, and storytelling — perfect for resumes, portfolios, and postgraduate university applications.

---

## 🔍 Project Goals

- Perform **data cleaning** and preprocessing on Netflix content data.
  
- Conduct detailed **exploratory data analysis (EDA)** using Python (Pandas, Matplotlib, Seaborn).
  
- Build **interactive dashboards** using **Power BI** to visualize key insights.
  
- Present trends, genres, formats, and country-level distribution in an engaging format.

---

## 🛠️ Tools & Technologies

- **Python**: Pandas, NumPy, Matplotlib, Seaborn
  
- **Power BI**: Data modeling, DAX measures, dashboard design
  
- **Jupyter Notebook**
  
- **Excel (optional)**: For data preview or export
